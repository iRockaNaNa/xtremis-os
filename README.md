# Xtremis OS

**A Nanatech Creative Solutions project.**

Xtremis OS is a custom Android ROM for the **Razer Phone 2** (`aura`) that
recreates the Windows 10 Mobile experience throughout the whole system —
not just a launcher skin. It is built on LineageOS and carries the Metro 10
app suite as built-in system apps.

## The experience

- Windows 10 Mobile Start screen with Live Tiles (Metro 10 Launcher as
  the default home)
- WP10-style lock screen and navigation bar, rebuilt in SystemUI
- Action Center, Settings and system UI restyled to match Windows 10
  Mobile, with its accent-color system, typography and sounds
- Metro 10 Messaging built in; a matching dialer to follow
- The Razer Chroma RGB logo stays fully working
- Arc-reactor boot animation, and a custom kernel underneath it all:
  **Another Really Cool Kernel — the ARC Kernel**

## Builds

Releases are numbered in the **MK series** — MK1, MK2, MK3… — and
published as GitHub Releases. A build only earns its MK number once it
has been verified running on the real phone.

The starting point is the **pre-MK stock baseline**: plain LineageOS
22.2, built and verified 2026-10-23, published as the pre-release
[baseline-stock-22.2](https://github.com/iRockaNaNa/xtremis-os/releases/tag/baseline-stock-22.2).
Every MK is compared against it.

## Reference

Fidelity is judged against an HP Elite x3 running genuine Windows 10
Mobile 1709.
